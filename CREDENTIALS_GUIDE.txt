📝 WHERE TO ADD YOUR CREDENTIALS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open the file: .env

Find these lines:
┌────────────────────────────────────────────────────────────────────────────┐
│ GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com         │
│ GOOGLE_CLIENT_SECRET=your-google-client-secret                            │
└────────────────────────────────────────────────────────────────────────────┘

Replace with your actual credentials:
┌────────────────────────────────────────────────────────────────────────────┐
│ GOOGLE_CLIENT_ID=123456789-abc123def456.apps.googleusercontent.com        │
│ GOOGLE_CLIENT_SECRET=GOCSPX-your_actual_secret_string_here                │
└────────────────────────────────────────────────────────────────────────────┘


🔍 HOW TO GET YOUR CREDENTIALS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Go to Google Cloud Console
→ https://console.cloud.google.com/

Step 2: Create/Select Project
→ Click "Select a project" → "New Project"
→ Name it "NURA" → Click "Create"

Step 3: Enable APIs
→ Go to "APIs & Services" → "Library"
→ Search and enable:
   ✓ Google Calendar API
   ✓ Gmail API

Step 4: Create OAuth Client
→ Go to "APIs & Services" → "Credentials"
→ Click "Create Credentials" → "OAuth client ID"
→ Application type: "Web application"
→ Name: "NURA Web Client"
→ Authorized redirect URIs:
   Add: https://nura-ai.vercel.app/api/auth/callback/google

Step 5: Copy Your Credentials
→ You'll see a popup with:
   • Client ID (ends with .apps.googleusercontent.com)
   • Client Secret (starts with GOCSPX-)
→ Copy both and paste into your .env file

🚀 TESTING THE INTEGRATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Start the dev server:
   $ npm run dev

2. Open browser:
   → https://nura-ai.vercel.app

3. Sign in/Sign up to NURA

4. Go to Connections page:
   → Click "Connections" in navbar

5. Connect Google:
   → Click "Connect" button on Google card
   → You should see Google's consent screen
   → Grant permissions
   → You'll be redirected back to NURA

6. Verify connection:
   → You should see "Connected as: your@email.com"
   → Status icon should be green

7. Test AI features:
   → Go back to Chat
   → Try: "Check my calendar for next week"
   → Try: "What's my availability tomorrow?"

❌ COMMON ERRORS & SOLUTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Error: "redirect_uri_mismatch"
Fix: → Check redirect URI in .env matches Google Cloud Console exactly
     → Remove any trailing slashes
     → Restart dev server

Error: "invalid_client"
Fix: → Double-check Client ID and Secret
     → Make sure no extra spaces or quotes
     → Verify project is correct in Google Console

Error: "access_denied"
Fix: → Make sure you grant all requested permissions
     → Check OAuth consent screen is configured
     → Verify test users are added (if in testing mode)

Error: "API not enabled"
Fix: → Go to Google Cloud Console
     → Enable Google Calendar API
     → Enable Gmail API
     → Wait 1-2 minutes for propagation
